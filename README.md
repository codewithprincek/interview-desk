# Desk Round

A public interview-prep site for **Java**, **Spring Boot**, **React**, **MySQL**, and **PostgreSQL**.

It includes easy and medium practice, bug snippets, spoken answers, SQL and plan drills, a timed mock, a project-story page, search, and a market brief aimed at interviews in late 2026. Answers, drill drafts, and the story stay in the browser.

```bash
npm install
npm run dev
```

Open the local URL Vite prints. `npm run build` writes a static site to `dist/`.

Version notes in the market section follow public release information as of October 2026, including [JDK 25](https://openjdk.org/projects/jdk/25/), [Spring Boot 4.1.2](https://github.com/spring-projects/spring-boot/releases/tag/v4.1.2), the [MySQL October 2026 GA releases](https://blogs.oracle.com/mysql/mysql-october-2026-ga-releases-now-available), and [PostgreSQL 18](https://www.postgresql.org/docs/18/release-18.html). Salary bands are rough India product-company ranges, not live offers.
