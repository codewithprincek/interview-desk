# Desk Round

A public interview-prep site for **Java**, **React**, **MySQL**, and **PostgreSQL**.

It includes easy multiple-choice practice, short latest-question notes, search, and a market brief aimed at interviews in late 2026.

```bash
npm install
npm run dev
```

Open the local URL Vite prints. `npm run build` writes a static site to `dist/`.

Version notes in the market section follow public release information as of October 2026, including the [MySQL October 2026 GA releases](https://blogs.oracle.com/mysql/mysql-october-2026-ga-releases-now-available), [JDK 25](https://openjdk.org/projects/jdk/25/), and [PostgreSQL 18](https://www.postgresql.org/docs/18/release-18.html). Salary bands are rough India product-company ranges, not live offers.
